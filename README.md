# NAVEEN KUMAR S — React Portfolio

A cinematic, responsive React + Vite portfolio designed for GitHub Pages.

## ⭐ Easy updates

Most content lives in:

`src/data.js`

Edit that file to change:
- name / role / email / links
- hero text
- about section
- stats
- skills
- projects and project links
- experience
- education
- certification
- leadership

You normally do not need to edit `App.jsx` or `styles.css`.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

Create a public repository:

`iamnaveen001.github.io`

Upload this project, then push to the `main` branch. The included GitHub Actions workflow automatically builds and deploys the site.

Live URL:

`https://iamnaveen001.github.io/`

## Updating later

1. Edit `src/data.js`
2. Commit and push
3. GitHub Actions automatically deploys the new version
